# InvestSG-Automation
For this project, I managed to automate decision processes specifically designed for the SGinvest Trading Tournament 2026.

I dedicated this repository to save my ideas of using a Telegram bot and a Streamlit interactive local web app through Python for my trading decisions.

The SGinvest Tournament 2026 was held around my finals, which created time constraints for any thorough research. Automation using Python and Streamlit helped me to provide technically-backed trading signals while juggling heavy study sessions during the tournament duration. I used MACD and RSI, popular retail indicators, to dictate my trading signals.

Furthermore, I also managed my risk using the Telegram bot and Streamlit to actively interact with my take-profit/stop-loss based on a set ratio. This helped me to execute proper risk management for my trades. With both scripts set, I managed to passively participate in this trading tournament without needing to sacrifice my studies.
